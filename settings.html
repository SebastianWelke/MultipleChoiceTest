Hinweis zur Anzahl richtiger Antworten

Legt fest, ob bei jeder Frage angezeigt wird, wie viele Antworten richtig sind.

Fragenkatalog

Wähle, mit welchem Fragenkatalog geübt wird. Statistik und Wiederholungs-Pool werden pro Katalog getrennt gespeichert.

Fragenkatalog hochladen

Lade eine JSON-Datei mit Fragen hoch, um z. B. für eine andere Prüfung zu üben.

Erwartetes Dateiformat

Ein Objekt mit name und fragen oder direkt eine Liste von Fragen. Beliebig viele Antwortoptionen (mind. 2) sind möglich; modul ist optional und dient als Themenfilter. 

[
  {
    "frage": "Welche Protokolle arbeiten auf Schicht 4?",
    "optionen": {
      "A": "TCP",
      "B": "IP",
      "C": "UDP",
      "D": "HTTP"
    },
    "richtig": ["A", "C"],
    "modul": "Netzwerke"
  }
]
